Teacher Guide: 2D Arrays – Total, Minimum & Maximum

Indexing, nested FOR loops, accumulators and selection: 8 runnable challenges worth 42 marks, from a whole-table total to a full 8-mark exam question.

Lesson overview

Learning objectives

  • Declare and index a 2D array as Array[Row, Column]
  • Use nested FOR loops to visit every element
  • Write total, maximum, minimum, count and average algorithms over a whole 2D array
  • Process per row and per column, resetting in the right place

Success criteria

  • I can say which cell Marks[3, 2] is
  • I initialise before both loops for whole-table results
  • I reset inside the outer loop for per-row/per-column results
  • My code runs and gives the right output

Prior knowledge

  • 1D standard methods (Week 9)
  • FOR…NEXT, IF…ELSE…ENDIF
  • The 2D river example (max and total of one column)

Keywords

2D array, row, column, index, nested loop, outer/inner loop, accumulator, counter

Starter: Find the cell

0–5 min

The page asks for random cells, e.g. "Click Marks[3, 1]". Students need 6 correct in a row; a wrong click resets the streak and explains the row/column it actually was.

Row first, column second, so the first number picks the student and the second picks the subject. What is Marks[3, 1]? (92: Student 3, Maths.)
Students reading [3, 1] as "column 3, row 1" (x, y as in maths graphs). That's the most common 2D indexing error.

Model answers 1–3 
// Challenge 1
DECLARE Marks : ARRAY[1:4, 1:3] OF INTEGER
Total ← 0
FOR Row ← 1 TO 4
    FOR Col ← 1 TO 3
        Total ← Total + Marks[Row, Col]
    NEXT Col
NEXT Row
OUTPUT Total

// Challenge 2
Maximum ← Marks[1, 1]
FOR Row ← 1 TO 4
    FOR Col ← 1 TO 3
        IF Marks[Row, Col] > Maximum
            THEN
                Maximum ← Marks[Row, Col]
        ENDIF
    NEXT Col
NEXT Row
OUTPUT Maximum

// Challenge 3: same as 2 with Minimum and <
For max/min, the loops start at 1, not 2. Unlike the 1D version, you can't skip "the first element" by starting one loop at 2: FOR Row ← 2 would skip the whole of row 1. Comparing Marks[1, 1] with itself is harmless.

Mark points (8)

  1. Nested FOR loops (1 TO 5, 1 TO 4) for input
  2. INPUT Marks[Row, Col] with a prompt
  3. Total ← 0 and accumulates every element
  4. Highest initialised from Marks[1, 1] after the input loop
  5. Lowest initialised from Marks[1, 1] after the input loop
  6. Correct > and < comparisons inside nested loops
  7. Average ← Total / 20 (or a count) after the loops
  8. Total, highest, lowest and average all output with messages

Model answer

FOR Row ← 1 TO 5
    FOR Col ← 1 TO 4
        OUTPUT "Enter mark for student ", Row, ", subject ", Col
        INPUT Marks[Row, Col]
    NEXT Col
NEXT Row
Total ← 0
Highest ← Marks[1, 1]
Lowest ← Marks[1, 1]
FOR Row ← 1 TO 5
    FOR Col ← 1 TO 4
        Total ← Total + Marks[Row, Col]
        IF Marks[Row, Col] > Highest
            THEN
                Highest ← Marks[Row, Col]
        ENDIF
        IF Marks[Row, Col] < Lowest
            THEN
                Lowest ← Marks[Row, Col]
        ENDIF
    NEXT Col
NEXT Row
Average ← Total / 20
OUTPUT "Total marks for the class: ", Total
OUTPUT "Highest mark: ", Highest
OUTPUT "Lowest mark: ", Lowest
OUTPUT "Class average: ", Average

A single loop that inputs and processes at the same time is also accepted. Highest/Lowest must then start at a value set before the loop, e.g. initialised on the first input, or 0 and 100 if the question states marks are 0–100.

Highest ← Marks[1, 1] placed before the input loop. The array is still empty, so the runner reports a value used before it was given one.
